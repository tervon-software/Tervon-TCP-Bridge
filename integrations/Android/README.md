# Android — интеграционные исходники

`route/` содержит перенесённые без изменения байтов Kotlin/Python исходники и тесты маршрута Android. Это **не** подтверждение работающего Android E2E.

Серверные Go-программы, изначально размещённые в `integrations/android-ingress/`, пока остаются на старых путях из-за импортов, workflow и релизных скриптов. Не переносить их без проверки сборки и отдельного согласования.
