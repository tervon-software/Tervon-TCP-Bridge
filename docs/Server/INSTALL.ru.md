# Установка Tervon TCP Bridge

**Текущая версия для Linux: v1.0.1.** Для новых серверов используйте [актуальное пошаговое руководство](INSTALL-v1.0.1.ru.md). Прежние образцы с фиксированными квотами и устаревшей схемой потока заменены конфигурацией версии v1.0.1.

- [Скачать Linux amd64 v1.0.1](https://github.com/tervon-software/Tervon-TCP-Bridge/releases/tag/v1.0.1)
- [Клонировать репозиторий по SSH и установить](INSTALL-v1.0.1.ru.md)
- [Описание конфигурации v1.0.1](CONFIGURATION.ru.md)
- [Диагностика](TROUBLESHOOTING.ru.md)

В конфигурациях обеих сторон **нулевые** `max_local_connections=0` / `max_streams=0` означают отсутствие фиксированного программного ограничения на число сессий. Ресурсы ОС по-прежнему конечны. Установщик предназначен для **новой** установки; он не перезаписывает уже работающую службу. Сертификаты mTLS, разрешённые backend и параметры сети настраивает администратор.
