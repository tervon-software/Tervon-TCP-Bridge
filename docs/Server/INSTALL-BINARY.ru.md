# Установка готового бинарника Tervon TCP Bridge

**Актуальная версия: Linux v1.0.1.** Эта страница сохранена как короткий переход к официальному руководству. Старые хеши, конфигурации и портовые схемы не применяйте к текущей сборке.

- [Пошаговая установка v1.0.1 на два новых Linux-сервера](INSTALL-v1.0.1.ru.md)
- [Проверенный бинарник и SHA256 в GitHub Release v1.0.1](https://github.com/tervon-software/Tervon-TCP-Bridge/releases/tag/v1.0.1)
- [Параметры конфигурации](CONFIGURATION.ru.md)

Готовый asset `tervon-bridge-linux-amd64` должен иметь SHA256:

```text
4f997b60bd777516339512ac71ddbb89b96d5bf9af979286ff3bd63690ea525b
```

Режимы `client` и `server` используют один бинарник; встроенные фиксированные квоты сессий в публичных шаблонах v1.0.1 отключены (`0`). Сертификаты, частные ключи и разрешённые backend создаются администратором. Установщик не обновляет работающую службу.
