# Tervon TCP Bridge v1.0.2 — Linux AMD64

Tervon TCP Bridge — двунаправленный TCP-мост поверх HTTP/2, TLS 1.3 и mTLS. Данные внутренних TCP-протоколов передаются без анализа VPN-payload.

## Изменения относительно v1.0.1

- RuntimePolicy объединяет авторизацию клиентских сертификатов (ACL) и разрешённые backend-маршруты в **одно атомарное поколение**.
- Новые HTTP/2-потоки проверяют ACL и получают список backend из одного снимка политики.
- Обновление `routes + authorized` по `SIGHUP` без перезапуска Bridge и без перенаправления уже установленных TCP-соединений.
- Новый набор маршрутов и ACL полностью проверяется до публикации. Некорректный кандидат не заменяет ранее активную политику.
- После успешной публикации ядро сообщает `M6_POLICY_RELOAD=PASS digest=<SHA256>`, где digest соответствует JSON пары `routes + authorized`.
- Все остальные параметры сервера, включая TLS, лимиты, Padding и Jitter, запрещено изменять через этот hot-reload.
- Механизмы TLS 1.3/mTLS, HTTP/2, framing, адаптивных Padding/Jitter и уже проверенных TCP-потоков v1.0.1 сохранены.

## Установка

Этот релиз не устанавливается автоматически и не изменяет работающие экземпляры Bridge. Для обновления действующей Linux-установки требуется отдельно согласованный cutover с сохранением действующего бинарника/конфигурации и возможностью отката.

Android ARM64-ядро `libtervonbridge.so` собрано отдельно и **не входит в Linux Release v1.0.2**. Работа в Android-приложении и испытания на устройстве относятся к отдельному этапу.
