# Tervon TCP Bridge v1.0.1 — Linux amd64

Tervon TCP Bridge — защищённый двунаправленный TCP-мост между серверами. Клиентский Encapsulator переносит TCP-данные по HTTP/2 поверх TLS 1.3 с взаимной аутентификацией сертификатами (mTLS), а серверный Decapsulator передаёт их только разрешённым backend, указанным администратором. Внутренние VPN-протоколы не декодируются.

## Возможности

- TLS 1.3, HTTP/2 и mTLS с проверкой сервиса по отпечатку клиентского сертификата.
- Двунаправленная передача TCP и корректная обработка закрытия/отмены соединений.
- Padding, адаптивный Rate Padding и Jitter для продолжительных потоков.
- Политика Jitter: до 4 мс на DATA-кадр и до 20 мс в секундном окне для соответствующего направления/потока. Это **политические пределы решения задержки**, а не измеренная гарантия сетевого RTT.
- Агрегированная телеметрия переданных полезных байтов, соединений, ресурсов, Padding/Jitter и ошибок, без регистрации payload.
- **Исправление v1.0.1:** устранена фиксированная квота 100 TCP-сессий. В шаблонах `max_local_connections=0` и `max_streams=0`, что отключает искусственный программный лимит количества одновременных сессий. Реальные ограничения CPU, памяти и операционной системы сохраняются.

## Установка

[Руководство по установке и настройке v1.0.1](INSTALL-v1.0.1.ru.md) — для двух **новых** Linux-серверов с systemd, собственной PKI, разрешёнными backend и явной активацией. Установщик проверяет опубликованный SHA256 и не изменяет действующую инсталляцию. Требуются два файла релиза: `tervon-bridge-linux-amd64` и `SHA256SUMS`. Дополнительно опубликован `BUILD_INFO` с происхождением сборки.

Исходники доступны в публичном каталоге `prototype/`. До отдельного объявления лицензии публикация исходников не означает предоставление open-source прав на копирование, модификацию и распространение.

## Ограничения

Поддерживается **TCP**, а не самостоятельный UDP/QUIC или WireGuard-туннель. Работа интеграции с Xray/3x-ui подтверждена в конкретной инфраструктуре; поддержку каждой панели и любой конфигурации VPN не обещаем. HTTP/2 через TLS 1.3 не гарантирует обхода любых сетевых блокировок и не является защитой от исчерпания ресурсов ОС.
