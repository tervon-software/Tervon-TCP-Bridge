## Порядок установки

Для **новых** машин используйте `install/install-bridge.sh`: он проверяет SHA256 и не запускает службы до явной команды `activate`. Для обновления уже работающей установки нужен отдельный план с резервной копией binary/JSON и возможностью возврата, без запуска установщика поверх живого Bridge.

Публикуемый исходный код находится в каталоге `prototype/` репозитория; публичный доступ к коду сам по себе не предоставляет лицензии на его модификацию или распространение. Условия распространения определяет правообладатель.
