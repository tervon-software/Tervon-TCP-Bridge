# Tervon TCP Bridge v1.0.2 на Android

TervonVPN использует мост (Bridge) для передачи TCP-трафика активного VPN-профиля через HTTP/2 и TLS 1.3 с взаимной проверкой сертификатов (mTLS). Android-мост подключается к Расшифровщику (Decapsulator) сервера подписки. Для работы нужны совместимое приложение, HTTPS-подписка и сервер, настроенный оператором.

Для VLESS TCP, VLESS XHTTP поверх TCP и Trojan TCP передача через мост (Bridge) проверена. Проверено также подключение через новый TCP inbound 3x-ui, добавленный после запуска сервера. Возможности моста (Bridge) в конкретной подписке зависят от её настроек и доступных профилей.

**Для администраторов сервера.** См. [пошаговую установку Bridge v1.0.2 M6 для Android](INSTALL-ANDROID-BRIDGE-M6.ru.md).

## Установка приложения

1. Скачайте [TervonVPN DPI 1.0.34 (сборка 35, ARM64)](https://github.com/tervon-software/Tervon-TCP-Bridge/releases/download/android-v1.0.34/tervonvpndpi-1.0.34%2B35.apk) из [официального Android-выпуска](https://github.com/tervon-software/Tervon-TCP-Bridge/releases/tag/android-v1.0.34).
2. Скачайте [файл SHA-256](https://github.com/tervon-software/Tervon-TCP-Bridge/releases/download/android-v1.0.34/tervonvpndpi-1.0.34%2B35.apk.sha256) в тот же каталог. На Linux проверьте файл командой `sha256sum -c 'tervonvpndpi-1.0.34+35.apk.sha256'`.
3. Откройте APK на Android. Если система запросит разрешение для источника установки, разрешите установку только для приложения, которым открываете этот файл.
4. При обновлении устанавливайте новый APK поверх существующего приложения. Если Android отклоняет установку из-за подписи, получите пакет из того же официального канала, с которого установлена текущая версия. Удаление приложения может привести к потере настроек и регистрации устройства.

## Подключение через Bridge

1. Импортируйте в TervonVPN HTTPS-подписку, выданную 3x-ui или Remnawave. Выберите совместимый TCP-профиль, подключите обычный VPN и убедитесь, что интернет работает.
2. Откройте **Диагностика → Настройки моста** и включите Bridge. Приложение берёт домен из URL подписки и обращается по HTTPS к `/.well-known/tervon-bridge`. В ответ получает адрес Decapsulator и параметры доверия.
3. Если подходящего сертификата устройства ещё нет, приложение создаёт ключ на устройстве и отправляет запрос на сертификат Registrar. Registrar выдаёт сертификат после успешного применения записи доступа в политике Decapsulator. Закрытый ключ остаётся на устройстве.
4. Приложение устанавливает mTLS-соединение с Decapsulator и направляет трафик выбранного профиля через Bridge. Сертификат используется только для доступа к мосту. Xray работает отдельно от выдачи сертификата и установления mTLS.
5. Откройте сайт или другое приложение, использующее TCP, и проверьте передачу данных в **Диагностика → Мониторинг моста**.

Для подписки Remnawave порядок действий в Android тот же. Чтобы включить Bridge, сервер подписки должен предоставлять Discovery и рабочий Decapsulator. Для автоматической синхронизации inbound требуется [Registrar с адаптером Remnawave](https://github.com/tervon-software/Tervon-TCP-Bridge/blob/a7734397f426266e4a1e95f048644c671f6a90c0/docs/Server/M6_3XUI_DYNAMIC_ROUTING.md#remnawave). Интеграция проверена с TLS-имитацией API.

Порт TCP inbound берётся из активного VPN-профиля. Адрес и внешний порт Decapsulator сообщает Discovery. Ручной ввод ключа, отпечатка или списка портов не требуется.

## Что показывает мониторинг

| Поле | Значение |
| --- | --- |
| Сервер отвечает | Приложение получило ответ Decapsulator по mTLS. Для проверки полного пути до интернета выполните отдельный запрос через VPN. |
| Версия, время работы, последний успешный ответ | Показатели серверного ядра и время получения ответа на телефоне. |
| TLS 1.3 / HTTP/2 / mTLS на устройстве | Потоки, для которых локальное ядро подтвердило успешный ответ Bridge с момента запуска. |
| TLS 1.3 / HTTP/2 / mTLS на сервере | Общий счётчик Decapsulator с момента запуска по всем его клиентам. |
| Отправлено и получено | Трафик локального ядра на устройстве. Объём показывается в МБ, скорость — в МБ/с. |

Прочерк означает, что показатель сейчас недоступен. Например, версия Decapsulator может отвечать на запрос статуса без поля серверного счётчика.

## Если подключение не работает

Для подключения Android должен иметь доступ к адресу и порту входного сервера Bridge. При строгом мобильном белом списке, исключающем IP входного сервера, переключатель **Обход DPI** не восстановит доступ. Проверка передачи данных по Wi‑Fi подтверждает работу в протестированной сети. Устойчивость к активной фильтрации в мобильной сети требует отдельного измерения. См. [границы применимости](TECHNOLOGIES-v1.0.2.ru.md#границы-применимости).

- **«Нет выбранной HTTPS-подписки»**. Выберите профиль из HTTPS-подписки, для которой оператор настроил Bridge.
- **Профиль не поддерживается**. Выберите TCP-вариант. Варианты на UDP или QUIC через этот TCP-мост не передаются.
- **Ошибка сертификата или доступа**. Проверьте, что используете актуальную подписку, и передайте оператору название ошибки из раздела диагностики. URL подписки, ключи и файлы сертификатов публиковать не нужно.
- **«Сервер не отдаёт статус»**. Проверьте обычный трафик отдельно. Для серверной карточки нужен Decapsulator с поддержкой `/v2/status`.

## Ядро ARM64 для разработчиков

`libtervonbridge.so` — исполняемое Go-ядро для Android ARM64, которое совместимое приложение размещает в `jniLibs/arm64-v8a/` и запускает как отдельный процесс с собственной защищённой конфигурацией. Это компонент приложения. Для полноценной интеграции требуются VPN-обвязка, подключение локального TCP-маршрута, HTTPS Discovery, управление сертификатом и конфигурацией Bridge. Простая подмена файла в произвольном VPN-клиенте этих функций не добавляет.

Проверенная сборка ARM64 ядра с локальным счётчиком:

```text
82e0d7d294e0fb120e75c3bc1dc4664c2057613a1ce6c35ae7210474f1f8b54b  libtervonbridge.so
```

Сведения о сборке и испытаниях приведены в [журнале M6](https://github.com/tervon-software/Tervon-TCP-Bridge/blob/work/m6-android-ingress/docs/Server/M6_3XUI_ROUTING_DEVELOPMENT_LOG.md). Для установки на сервер используйте [руководство Linux](INSTALL-v1.0.2.ru.md).
